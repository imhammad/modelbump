# ADR 0002: Apache License 2.0

- **Status:** Accepted
- **Date:** 2026-10-07

## Context

ModelBump should be easy for companies to adopt and for researchers to reuse.

## Decision

License the project under the **Apache License 2.0**.

## Alternatives considered

- **MIT:** shorter and equally permissive, but has no explicit patent grant.
- **GPL-3.0:** copyleft would discourage company adoption of a developer tool.

## Consequences

- Permissive use, including commercial, with an explicit patent grant and patent-retaliation clause.
- Contributions are accepted under the same license.
