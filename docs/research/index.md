# Research

ModelBump is also a research project aiming at a peer-reviewed paper.

## Research questions (draft)

| RQ | Question |
|----|----------|
| RQ1 | How accurately and how early can static analysis detect LLM-model dependencies that are about to be retired? |
| RQ2 | Can sequential statistical testing detect real behavioural regressions between model versions at bounded cost, with a controlled false-alarm rate? |
| RQ3 | How effective are automated regression-suite synthesis and prompt repair at restoring behaviour after a migration? |
| RQ4 | Is the end-to-end output useful to developers? |

## Key prior work

- H. L. Kim. *When the Model Retires: An Empirical Study of LLM Migration in Open-Source Applications.* arXiv:2609.31288, 2026. [arXiv](https://arxiv.org/abs/2609.31288)
- W. Ma, C. Yang, C. Kästner. *(Why) Is My Prompt Getting Worse? Rethinking Regression Testing for Evolving LLM APIs.* CAIN 2024. [arXiv](https://arxiv.org/abs/2311.11123)
- L. Chen, M. Zaharia, J. Zou. *How Is ChatGPT's Behavior Changing over Time?* Harvard Data Science Review, 2024. [arXiv](https://arxiv.org/abs/2307.09009)
